One sentence that could have replaced an entire pointless meeting — an entry for the [make.fun bounty "The Meeting That Should Have Been One Line"](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c). Referral: https://make.fun/r/0ene8b3q

> "The client already said yes in the email none of us read, so this meeting is just twelve people billing an hour to read it out loud."

## Run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints the exact same text to stdout.
